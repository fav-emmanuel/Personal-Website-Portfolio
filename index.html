Featured Flagship • AI & Embedded Hardware

OMNI — Personal AI Hardware Assistant

FastAPI • PostgreSQL (pgvector) • ESP32-S3 • PlatformIO

View Architecture on GitHub →

OMNI is a standalone, all-in-one AI personal assistant engineered from the ground up to bridge cloud intelligence with custom portable hardware. Designed to run on a Waveshare ESP32-S3 1.75-inch AMOLED round touch display board with rechargeable battery and GPS support, OMNI acts as a dedicated daily companion rather than just another browser tab.

Powered by a Python FastAPI backend and a PostgreSQL database utilizing pgvector, the system maintains multi-tier persistent memory—allowing it to recall context, log daily meals, workouts, habits, and finances, ping connected devices, and operate seamlessly alongside a full browser simulator.

Core Capabilities

  • • Multi-Tier Memory: Vector-backed long-term recall with PostgreSQL & pgvector.
  • • Life & Habit Logging: Structured tracking for nutrition, workouts, and finances.
  • • Embedded Firmware: Custom PlatformIO build for ESP32-S3 AMOLED touch hardware.
  • • Device Ecosystem: Cross-device pinging and an interactive web simulator.

About Me

Hello! I’m Favour, a software engineering undergraduate at York St John University with a deep-rooted passion for building, problem-solving, and creative execution.

My journey into technology didn’t start in a traditional vacuum—it grew out of my love for digital media editing and motion design. Spending hours editing videos and working with kinetic typography taught me patience, precision, and an eye for clean aesthetics, which naturally translated into web development and software engineering. I love taking complex, messy problems and breaking them down into structured, elegant solutions.

Rather than just writing code for assignments, I have a habit of building custom programs and automated tools from scratch to solve real friction points in my day-to-day life—whether that's streamlining personal workflows, managing tasks, or experimenting with new full-stack architectures. Through initiatives like my 'Road to 25' portfolio series, I'm constantly pushing my limits across JavaScript, TypeScript, Python, and modern web frameworks to craft software that is as functional as it is polished.

Tech Stack

  • Core Languages: TypeScript, Python, Go, JavaScript, SQL
  • Frontend & UI: React, Next.js, Tailwind CSS, HTML5/CSS3
  • Backend & APIs: FastAPI, Node.js, GraphQL, REST, WebSockets
  • Data, AI & Pipelines: PostgreSQL (pgvector), SQLite, Pandas, Airflow, RAG
  • Cloud, DevOps & Embedded: AWS (Lambda), Docker, Pytest, Git, ESP32-S3 (PlatformIO)
