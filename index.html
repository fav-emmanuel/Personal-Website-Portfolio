Featured Flagship • AI & Embedded Hardware

OMNI — Personal AI Hardware Assistant

FastAPI • PostgreSQL (pgvector) • ESP32-S3 • PlatformIO

View Architecture on GitHub →

OMNI is a standalone AI personal assistant engineered to bridge cloud intelligence with portable embedded hardware on a Waveshare ESP32-S3 1.75-inch AMOLED round touch display board with rechargeable battery and GPS support.

Backed by a Python FastAPI backend and PostgreSQL with pgvector, OMNI supports multi-tier persistent memory, daily logging, device pinging, and an interactive web simulator.

Core Capabilities

  • • Multi-Tier Memory: Vector-backed recall with PostgreSQL & pgvector.
  • • Life & Habit Logging: Structured tracking for routines and goals.
  • • Embedded Firmware: Custom PlatformIO build for ESP32-S3 AMOLED hardware.
  • • Device Ecosystem: Cross-device pinging and browser simulator.
